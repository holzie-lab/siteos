# SiteOS

SiteOS is an open-source construction site and technical-office operations platform.

## Scope

- Projects and areas
- Activities / work packages
- Daily reports
- Materials and stock
- Quality records
- Drawings and RFIs
- Photos
- Primavera P6 integration roadmap
- Role-based access roadmap

## Data policy

This public repository must contain **synthetic data only**. Do not commit real company, client, project, site, personnel, drawing, photo, XER, PDF, Excel, CSV or credential data.

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` if you want to connect a development Supabase project.
