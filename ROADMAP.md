# SiteOS Roadmap

SiteOS is developed in small, reviewable milestones. The roadmap is directional; issues and pull requests are the source of truth for active work.

## 0.1 — Open-source foundation

- Reproducible build and CI
- Repository data-safety checks
- Contribution and security policies
- Issue and pull-request workflow
- Synthetic demonstration data only

## 0.2 — Core project operations

- Project and area setup
- Activity/work-package CRUD
- Daily reports and site events
- Materials and stock movements
- Basic dashboard metrics

## 0.3 — Quality and documents

- Inspection and quality records
- Drawing and revision register
- RFI and issue register
- Traceable links between activities and records

## 0.4 — Planning interoperability

- Vendor-neutral schedule data model
- Primavera P6 XER parsing without committed production XER files
- Schedule snapshots and relationships
- Import validation and error reporting

## 0.5 — Field usability

- Mobile-first workflows
- Offline-friendly capture
- Photo metadata without public project media
- Import/export adapters for spreadsheet-based teams

## Longer term

- Stable API contracts
- Plugin/integration model
- AI-assisted retrieval and maintainer automation with clear separation between generated suggestions and recorded project facts
