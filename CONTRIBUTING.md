# Contributing to SiteOS

Thanks for contributing to SiteOS.

## Development
1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Configure the Supabase variables for your development project.
5. Run `npm run dev`.

## Pull requests
- Explain the problem and the proposed change.
- Keep pull requests focused.
- Include screenshots for meaningful UI changes.
- Include migration notes for database changes.
- Do not include credentials, customer data, private project documents, or real construction-site records.

## Issues
Use GitHub Issues for reproducible bugs, feature requests, and technical discussions.

## Domain contributions
Examples and documentation should use synthetic project data unless a dataset is explicitly licensed for redistribution.

## Code review
Automated tools, including Codex, may help with review. Final merge decisions remain with human maintainers.
